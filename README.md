# AI 업무 도구 모음 (ai-work-tools)

설치 없이 브라우저에서 바로 쓰는 무료 도구입니다. 서버, 로그인, 데이터베이스, 외부 AI API가 없습니다. 입력한 내용과 이미지는 내 브라우저 밖으로 나가지 않습니다.

| 도구 | 하는 일 |
|---|---|
| [PRD 메이커](prd-maker/) | 아이디어 빈칸을 채우면 기획 문서(PRD)와 AI에게 줄 프롬프트를 만들어 복사하거나 .md로 내려받습니다 |
| [릴스, 쇼츠 커버 메이커](cover-maker/) | 화면 캡처에 큰 훅 문구를 얹어 1080x1920 커버 PNG로 저장합니다. 프로필 그리드(3:4)에서 잘리는 영역을 미리 봅니다 |

## 직접 실행
폴더의 `index.html`을 브라우저로 열면 됩니다.
