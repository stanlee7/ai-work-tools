# 회의 메모 할 일 표

실행 방법: `index.html`을 브라우저에서 엽니다.

메모의 할 일처럼 보이는 줄을 골라 할 일, 담당, 기한, 원문 줄 표로 정리합니다. 표를 직접 수정하고 행을 추가하거나 삭제한 뒤 엑셀용 탭 구분 텍스트, Markdown, CSV로 내보낼 수 있습니다. 처리는 브라우저 안에서 규칙으로 이루어집니다.

입력 예:

```text
- 민지: 제안서 초안 작성, 금요일까지
- 다음 주 월요일까지 일정 확인
```

출력 예:

| 할 일 | 담당 | 기한 | 원문 줄 |
| --- | --- | --- | --- |
| 제안서 초안 작성 | 민지 | 날짜 (금요일까지) | - 민지: 제안서 초안 작성, 금요일까지 |
| 일정 확인 |  | 날짜 (다음 주 월요일까지) | - 다음 주 월요일까지 일정 확인 |

날짜는 도구를 여는 날을 기준으로 표시합니다. 규칙으로 놓친 내용이 있을 수 있으므로 결과를 확인해 주세요.
