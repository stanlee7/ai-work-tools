# 릴스, 쇼츠 커버 메이커

1. `index.html`을 브라우저에서 엽니다.
2. 영상 캡처 이미지를 선택하거나 미리보기로 끌어다 놓습니다.
3. 두 줄 훅과 작은 태그를 입력하고 배치와 강조색을 고릅니다.
4. 이미지 위치와 확대를 조절하고 필요하면 그리드 미리보기를 켭니다.
5. PNG 저장을 눌러 1080 × 1920 파일을 받습니다.

저장하는 것 없음. 이미지는 브라우저 안에서만 처리합니다.

실행: `index.html`을 브라우저에서 엽니다. 입력 예: 영상 캡처 이미지 + 두 줄 훅 → 출력: `reels-cover-1080x1920.png`.
