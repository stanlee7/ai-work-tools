# 개인정보 가리기

`index.html`을 브라우저에서 열면 사용할 수 있습니다. 서버나 데이터베이스 없이 입력 내용을 브라우저 안에서 처리합니다. 글꼴은 Pretendard를 jsDelivr에서 불러옵니다.

사용 예: `연락처 010-1234-5678` 입력 후 **가리기**를 누르면 `연락처 010-****-5678`처럼 표시됩니다. 표시어 방식을 고르면 같은 값에는 같은 표시어가 붙습니다. 되돌리기 표 CSV에는 원래 값이 포함되므로 내 PC에만 저장하세요.

형식으로 찾는 도구라 이름과 주소는 직접 확인하세요. 계좌번호처럼 보이는 숫자열 찾기는 기본으로 꺼져 있습니다.
